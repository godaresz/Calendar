# สุ่มวันตรวจสอบกะทำงาน

ตารางผู้ตรวจสอบพื้นที่รายวัน ครบทั้งกะ A และ B อิงปฏิทินวันหยุดบริษัท IMCT & LINEX (เม.ย. 2026 – มี.ค. 2027)

- เปิด `index.html` ได้เลย ไม่ต้องติดตั้งอะไร (รองรับมือถือ)
- ทุกคนที่เปิดลิงก์เดียวกันจะเห็นตารางเดียวกัน (สุ่มแบบกำหนด seed)
- กด **สุ่มใหม่** จนพอใจ → กด **คัดลอกลิงก์แชร์** ส่งให้ทีม ลิงก์จะจำผลสุ่ม เดือน วันหยุด และรายชื่อไว้

## เปิดออนไลน์ด้วย GitHub Pages
Settings → Pages → Source: Deploy from a branch → เลือก branch และโฟลเดอร์ `/ (root)`
